retrieved_at: 2026-08-01
method: WebSearch (Claude web search tool), 4 queries per niche — (1) generic head term, (2) consumer person-form "near me" query, (3) "[head term] cost", (4) "[head term] toronto". Top ~8–10 returned organic links classified per query into: BIG PLATFORM (Angi/Thumbtack/Houzz/HomeAdvisor/Yelp), NATIONAL CONTENT, LOCAL CONTRACTOR, FRANCHISE, PROGRAMMATIC/EMD LEAD-GEN, FORUM/UGC, OTHER. Scoring: 5 = weak/thin SERPs a data-rich local page should beat; 1 = locked by strong platforms/brands.
limitation: **WebSearch approximates organic results only — no ads, no local pack / map results, no SERP features visible; the index is US-localized (Toronto queries reflect a US vantage). All beatability scores are organic-only beatability.** Result order may not exactly match live Google rank; some queries returned fewer than 8 results. Only results actually returned are classified — nothing inferred. Live "near me" SERPs will be more competitive than shown (local pack absorbs clicks), which favors cost/data/research pages over directory-style pages.
note: this file supersedes a prior draft of the same audit (same scores reached independently: 5/5/5 decorative+restoration, 4/4/4/4 others); all classifications below are from searches run 2026-08-01 with the exact person-form terms in the P0 plan.
