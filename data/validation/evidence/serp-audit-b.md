# SERP-Quality Audit — Batch B (7 niches)

- retrieved_at: 2026-08-01
- method: 4 WebSearch queries per niche — (1) head term, (2) consumer person-form + "near me", (3) head term + "cost", (4) head term + "toronto". Top ~6–10 organic results visible per query classified into: BIG PLATFORM (Angi/Thumbtack/Houzz/HomeAdvisor/Yelp), NATIONAL CONTENT, LOCAL CONTRACTOR, FRANCHISE, PROGRAMMATIC/EMD LEAD-GEN, FORUM/UGC, OTHER. Only results actually returned are listed; result counts vary because the tool returned different numbers per query.
- **Tool limitation (applies to everything below): WebSearch approximates organic results and does not show ads or the Google local pack/map results. Beatability scores therefore refer to organic content results only.** Real money-query SERPs will additionally carry LSA ads and a 3-pack above these results.
- Query adaptations: sauna cost query run as "sauna installation cost" ("sauna builders cost" is not a real consumer query); land clearing & forestry mulching run as "forestry mulching" (generic), "land clearing near me", "forestry mulching cost". Toronto returned usable results for all 7 niches — no city substitution needed.
- Scale: 5 = weak/thin SERPs a data-rich local page should beat; 1 = locked up by strong platforms/brands.
